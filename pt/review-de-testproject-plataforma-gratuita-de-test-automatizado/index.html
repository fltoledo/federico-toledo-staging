Review de TestProject (plataforma gratuita de test automatizado)

En este post te comparto un review de TestProject. Este análisis fue realizado por Nicolás Reina de Abstracta sobre esta plataforma gratuita de test automatizado. Como ya comenté en algún post y charlas anteriores, hay muchas empresas que están migrando a opciones open source, y esta plataforma gratuita puede ser un excelente complemento agregando muchas funcionalidades bien interesantes.

Te voy a compartir lo que estuve aprendiendo sobre TestProject.io, una plataforma online gratuita de uso ilimitado. Si bien TestProject pertenece actualmente a Tricentis, la promesa es que mantendrán estas funcionalidades de manera gratuita:

¿Qué es TestProject.io? 

TestProject es una plataforma de automatización de pruebas end to end gratuita para pruebas web, mobile y de API. Está construido sobre herramientas de código abierto como Selenium y Appium y que es compatible con diversos sistemas operativos (Windows, macOS, Linux, iOS, Android, servicios web).

De momento el SDK de esta herramienta está disponible en los lenguajes de programación Java, C# y Python. Próximamente estará disponible en JavaScript.

Ofrece una variedad de features muy interesantes que veremos más adelante, pero lo más impactante de esto es que todas ellas son 100% gratuitas y no poseen planes pagos puesto que buscan retribuir a la comunidad de automatización de pruebas a través de lo que llaman Free Forever Plan.

Ofrece un mecanismo de Addons (porción de código que realiza una acción que puede ser reutilizada por cualquier miembro de la comunidad). El listado de todos ellos está disponible de forma pública, sin embargo para acceder a los mismos se debe formar parte de la comunidad. Acá se puede acceder al repositorio de Addons: https://addons.testproject.io/

¿Qué features ofrece?

Al realizar una breve recorrida por su sitio web podemos encontrar que TestProject.io está basada en cuatro features interesantes y útiles para nuestras pruebas.

  1. Smart Test Recorder para aplicaciones web y mobile

Posee la funcionalidad de crear pruebas automatizadas utilizando un grabador de pantalla donde las aplicaciones web son grabadas simplemente ingresando a la url donde está alojada la misma. Por otro lado, podemos conectar un dispositivo móvil a la computadora, donde podremos proyectar la pantalla y realizar la grabación. 

Dentro de lo que es “recorder” se hace mucho hincapié en particularidades como las que se mencionan a continuación:

  • Duplicación de pantalla móvil
  • Inspector de elementos
  • Explorador de elementos
  • Editor de prueba
  • Sugerencias de acciones basadas en los Addons de la comunidad
  • Exportación de código generado a Java, C# o Python
  1. Complementos compartidos (Addons)

Como se mencionó previamente, los Addons son colecciones de código abierto para la comunidad, donde teniendo en cuenta la necesidad del usuario se adapta en mayor o menor medida a nuestro proyecto.

  1. SDK para Selenium y Appium precargado

Asimismo, el agente de esta herramienta posee librerías y dependencias de Selenium y Appium para que no debamos instalar otros complementos. 

De momento el SDK de esta herramienta está disponible en los lenguajes de programación Java, C# y Python.

  1. Analíticas e indicadores en detalle

TestProject evalúa los resultados de las ejecuciones que llevamos a cabo, no solo a modo de si las mismas son correctas o no, sino que brinda información acerca de la calidad/salud del producto según el detalle solicitado (navegadores y dispositivos).

Free Forever Plan

Algo que sorprende de buena manera es el hecho de que no poseen una versión paga ni una versión free trial ni nada por el estilo. Sino que todas sus funcionalidades forman parte del llamado Free Forever Plan como lo comentábamos previamente. En ningún momento se solicita un número de tarjeta o cuenta (lo que muchas veces lleva a desconfiar a los usuarios). Se puede cancelar la suscripción en cualquier momento. 

Dicho plan incluye, entre otras, las funcionalidades que listamos aquí:

  • Usuarios ilimitados para colaborar
  • Ejecución de prueba ilimitada
  • Proyectos ilimitados
  • Historial de ejecución ilimitado
  • Acceso ilimitado a la API
  • Almacenamiento ilimitado
  • Grabador de prueba inteligente para web, Android e iOS
  • Soporte para iOS en Windows
  • Exportar pruebas grabadas a código
  • Integraciones externas (Jenkins, Slack, etc.)

Trabajo colaborativo e integraciones

Parte de lo destacable de TestProject es la fácil colaboración entre miembros de un mismo equipo dentro de un proyecto. Simplemente necesitaremos de un mail para agregar a un colaborador a nuestro proyecto y así brindarle los permisos necesarios para trabajar juntos.

En la misma línea, para poder colaborar con mayor facilidad, es posible integrar la herramienta de diferentes formas. Por ejemplo, es posible utilizar su API (lo cual puede ser útil para disparar los tests desde un engine de CI/CD por ejemplo) o integrar con Slack mediante webhooks.

Mi experiencia utilizándola

Hice mis primeras pruebas con la herramienta para este review de TestProject, pero en Abstracta estamos con ganas de darle más oportunidades y ganar más experiencia con ella.

En cuanto a la descarga e instalación del agente de TestProject vi que es muy sencilla y entendible. No necesita de ningún tipo de cambio o requisito de configuración especial en nuestro sistema operativo, lo que configura un buen paso para su utilización. Al descargar el .exe e instalarlo se brindan videos tutoriales para poder conectar el agente descargado y registrarlo.

Te dejo por acá algunas capturas que tomé en mis pruebas para que te hagas una idea de qué brinda la herramienta y cómo luce.

Otra cosa a destacar es la variedad de Addons que ofrece, facilitando tareas que típicamente dan mucho trabajo, como por ejemplo, realizar acciones sobre PDFs o trabajar con cosas muy particulares como bases de datos, APIs, etc.

Reflexiones finales sobre mi review de TestProject

Pocas veces encontramos una herramienta que sea 100% gratuita, y eso ya es algo muy bueno. A eso le podemos sumar que es una herramienta sencilla y amigable pero no por eso menos robusta. Es una gran opción para complementar algunas features de colaboración y reporte que muchas veces se extrañan al usar Selenium o Appium.
