Sitios de prueba para practicar

Siempre se necesitan sitios de prueba para practicar, ya sea para cursos, workshops, webinars, probar herramientas nuevas, etc. Por eso en este post te quiero dejar una lista de los sitios que generalmente usamos, y ya de paso me sirve a mí para ir agregando nuevos cada vez que encuentro otro 🙂

Sistemas de e-commerce

Demoblaze

Sistema de e-commerce provisto por Blazemeter para practicar automatizando con JMeter y ejecutar con Blazemeter. Incluye una sección con un video para incluso poder probar el protocolo HLS. Lo curioso es que este sitio lo desarrollamos en Abstracta 🙂 También está disponible en esta URL http://demo-ecommerce.abstracta.us/

OpenCart

Para nuestros cursos nosotros instalamos una versión del sistema de e-commerce opensource llamado OpenCart. 

WPmobilepack

Sistema de e-commerce muy simple. 

2Checkout

Sandbox del sistema 2checkout que no solo es un sistema de e-commerce para clientes, sino que cuenta con muchas más funcionalidades, reportes, ventas, etc. 

Otros sistemas

DBank Demo

Sistema bancario de ejemplo. 

OrangeHRM

OrangeHRM es un sitio de demo del producto opensource para gestión de recursos humanos, el cual sirve muy bien para probar un sistema real. 

Computer-Database

Sitio de pruebas provisto por Gatling (herramienta para pruebas de performance). Se trata de un sitio con una base de datos de computadoras, donde se cuenta con un listado con varias columnas y un filtro de búsqueda. 

PetStore

Sistema de pruebas provisto por la herramienta Octoperf (de pruebas de performance). Es un pet store con distintos listados, filtros, etc. 

Basic Calculator

Calculadora con interfaz web para aprender Selenium probando una página con funcionalidad, provista por Mike Talks.

Space travels

Sistema de reserva de viajes al espacio, provisto por Testim a modo de demo de su herramienta de automatización.

Time and date

Es un sitio con muchísimas funcionalidades relacionadas a cálculo de tiempo y fechas. Por ejemplo tiene esta herramienta Working days calculator que es una calculadora de días hábiles entre dos fechas. También acá podes ver a qué hora sale y se oculta el sol en distintos lugares del mundo o usar el convertor de husos horarios.

Ideales para probar herramientas de automatización de pruebas web

DemoQA

Se cuenta con un listado de elementos típicos con los que uno se encuentra en sitios web. Está bien orientado a practicar testing automatizado, para poder ver cómo atacar cada una de las cosas particulares con las que uno se puede encontrar, como elementos de una lista que se ordenan con drag and drop, inputs de distintos formatos, etc. 

The-Internet

Dave Haeffner en Elemental Selenium ofrece este sitio para también probar distintas situaciones.

Selenium Easy

Misma idea que el anterior. Provisto por Smartbear CrossBrowserTesting.

CompendiumDev

Misma idea que el anterior. 

Selenium Test Pages

Similar a los anteriores, con muchos ejemplos concretos y micro aplicaciones. Gracias Alan Richardson!

ToDoMVC

Es un sitio que ofrece acceso a la misma aplicación web para gestión de tareas, pero implementada en diferentes tecnologías. Esto puede ser realmente útil para probar qué tan bien se adapta nuestra herramienta de automatización a un framework de desarrollo en particular.

Angular – Snack-bar

Este sitio está especialmente interesante por tratarse de una aplicación desarrollada con Angular, lo cual generalmente trae ciertas complicaciones extras.

Ideales para probar herramientas de pruebas a nivel de servicios (API, SOAP, Rest)

Public-APIs

Ahí hay una lista extensa con distintas interfaces para practicar.

PetStore

También se cuenta con un pet store provisto por Swagger con distintos métodos accesibles. 

Chuck Norris

Una API JSON para obtener los famosos Chuck Norris’ facts.

Ideales para pruebas de seguridad

Juice-Shop

Juice-shop es un famoso sitio de OWASP utilizado para probar vulnerabilidades de seguridad. 

Gruyere

Sistema con el mejor nombre, dado sus agujeros de seguridad 🙂 Junto con este sistema tenemos esta guía que permite aprender probando.

TicketMagpie

Sistema desarrollado con fines de entrenamiento, incluyendo fallos de seguridad típicos en el OWASP top 10.

Damn Vulnerable Web Application

Se trata de una aplicación PHP/MySQL web que es “damn vulnerable“. Es ideal para practicar skills de tester de seguridad.

Otras listas

No soy el único al que se le ocurrió hacer listas, por acá quiero ir dejando registro de las que encuentro:

  • https://github.com/BMayhew/awesome-sites-to-test-on

Cerrando

Al momento de capacitarte, probar herramientas, explicar técnicas a alguna otra persona, necesitamos sitios de prueba. En ocasiones necesitamos sitios que sean lo más parecido a un sitio real, y en otras ocasiones sitios que nos permitan experimentar ciertas dificultades o particularidades de las herramientas que queremos probar. Acá te compartí una lista extensa de sitios de prueba para practicar.  ¿Conocés alguno más que pueda agregar a esta lista?
