Webinar: Pruebas de mainframe con herramientas opensource

Mañana 5 de diciembre a las 15 hs en Uruguay, Roger Abelenda de Abstracta estará dando un webinar organizado por BlazeMeter, donde hablará de pruebas de mainframe con herramientas opensource (¡desarrolladas por nosotros!). 

En este webinar se mostrará el plugin de RTE desarrollado sobre JMeter para automatizar pruebas de mainframe. Si bien el foco original siempre fue el de pruebas de performance, al ver la herramienta hoy creo que es la mejor (y tal vez única) opción para automatizar también las pruebas funcionales sobre este protocolo. 

Además, en el proceso de desarrollo de esta herramienta de automatización, se terminó desarrollando otra herramienta open source que es útil para generar test doubles (para virtualizar servicios, algo así como un mock). Wiresham sirve para esto mismo, pudiendo así facilitar las pruebas de sistemas que tienen dependencias con mainframe, pudiendo sustituir estas llamadas al servicio real por un mock que responde de igual manera. 

Si te interesa, deberías registrarte aquí. Abajo te dejo la descripción que aparece en el sitio donde lo promocionan los amigos de BlazeMeter:

Testing Mainframe Environments Using Open Source Tools

Testing mainframe systems usually requires legacy tools and specific platform knowledge.

Using open source tools such as JMeter, is easy to create tests over RTE protocol. This enables the same script to check functional aspects as well as performance behavior. 

Join Roger Abelenda, Technical Director at Abstracta, for an introduction to using the RTE plugin in JMeter for performance and functional tests, and how to mock mainframe apps.

You’ll learn:

  • How to build RTE scripts using JMeter to test mainframe apps.
  • How to create RTE mocks to avoid creating mainframe environments.
  • How to run functional and performance tests in BlazeMeter and benefit from scalability, distributed testing, and real-time and comprehensive test results.

Tomorrow! Don’t miss this webinar at 10 am PT by @BlazeMeter & @rabelenda on how you can use #JMeter to test over RTE protocol, which enables the same script to check functional aspects as well as performance behavior! Register here: https://t.co/HOeRd2iuuB
